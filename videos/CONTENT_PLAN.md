# Agent Zoo: short video plan

Two 16:9 desktop videos, approximately 20–25 seconds each. The website remains in English; these notes are for production and posting.

## 1. Smooth tour — first impression

| Time | Screen | Point |
| --- | --- | --- |
| 0–8 s | Live landing page: headline, Grok routing diagram, five-step sequence | One orchestrator, four specialist pets |
| 8–15 s | Zoo dashboard and command map | The hierarchy is visible as a working product |
| 15–18 s | Animals directory | Each animal has a distinct job and public status |
| 18–21 s | Owl passport with animated 3D model | Pets have identities, budgets, and detailed pages |
| 21–23 s | Founding enclosure | Grok sits above the four pets |
| Final card | agentzoo.tech | Visit the habitat |

Suggested post copy: “One mind. Four instincts. Meet Grok’s living Agent Zoo.”

## 2. Guided walkthrough — what a user can do

| Time | Action | Point |
| --- | --- | --- |
| 0–4 s | Cursor enters the zoo and opens Enclosures | Clear route from landing to product |
| 4–6 s | Test wallet signs in | Creation is tied to a guardian wallet |
| 6–10 s | Type an AI agent profile and register it | Users bring their own orchestrator |
| 10–14 s | Create a named enclosure and assign the head agent | One agent leads a territory |
| 14–18 s | Create a Raven pet and assign its agent | Pets can have their own agents |
| 18–22 s | Open the saved enclosure and Raven passport | The hierarchy persists and is inspectable |
| Final card | agentzoo.tech | Build your habitat |

Suggested post copy: “Create an agent. Give it a habitat. Build a team of pets.”

The smooth tour captures the public production domain. The guided creation sequence uses the same production build against an isolated local database and an automatically generated test wallet, so no sample records are added to the public site. Both exports are silent, ready for a soundtrack or voiceover.
